# 乖乖的专属互动乐园 🎠💕

这是老公专门为乖乖打造的甜蜜互动网页仓库！这里收集了我们相爱以来的点点滴滴，有哄老婆开心的小动画，有记录我们旅行和心情的日记，还有只有我们俩能看的小秘密喔~ 

## 📂 网页目录导航

这里有各式各样好玩的小网页，老公把它们都整理好啦：

- 🏠 **主页面 (`index.html`)**：整个乐园的入口，点击这里开启甜蜜之旅！
- 🐶 **哄老婆专用 (`cheer_up.html`)**：乖乖如果生气了，一定要点开看看，点不到拒绝按钮的哦~ 
- ✨ **赛博烟花 (`cyber_fireworks.html`)**：鼠标点击就能放烟花，给你的赛博浪漫。
- 📷 **甜蜜合影 (`sweet_photo.html`)**：我们的心动瞬间都在这里，图片加载可是秒开的！
- 📖 **互动日记 (`interactive_diary.html`)**：用来记录我们的心情曲线、旅行计划和书影音评价。
- 🌙 **时间胶囊 (`time_capsule.html`)**：把想对未来彼此说的话藏在这里。
- ♟️ **甜蜜五子棋 (`gomoku.html`)**：闲下来的时候，就来陪老公下局五子棋吧！
- 🎇 **粒子魔法 (`particle_magic.html`)**：唯美梦幻可以用手操控的粒子动画。
- 🖱️ **鼠标魔法 (`mouse_interaction.html`)**：好玩的鼠标交互小网页。
